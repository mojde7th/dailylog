gadget 01

HTML Macro

ساندبکس HTML داخل صفحه. برای HUD، جدول استاتیک، یا iframe به Metabase/Grafana. دادهٔ زنده از Postgres را مستقیم از این ماکرو query نمی‌کند مگر backend جدا.

gadget 02

SQL / JDBC macro

مسیر Marketplace: plugin با datasource JDBC به همان confluencedb یا یک schema فقط‌خواندنی. SELECT روی view، نه روی جدول‌های هستهٔ Confluence مگر دقیقاً بدانی چه می‌کنی.

gadget 03

iframe BI

اگر جدول‌هایت خارج از Confluence‌اند، درست‌ترین معماری: Postgres view → Metabase question → iframe داخل HTML Macro. Confluence نمایش است، نه OLAP.

gadget 04

Page Properties Report

برای metadata صفحه‌ها، نه برای ردیف‌های عملیاتی. شاخص وضعیت runbook، نه timeseries.

gadget 05

Chart from table

ماکرو Chart روی جدول Confluence. منبع باید جدول صفحه باشد. برای PG زنده ضعیف است مگر SQL plugin جدول را اول بریزد.

gadget 06

Jira Issues

اگر Jira هم هست، gadget رسمی Issues/Filter. به Postgres اپ تو وصل نیست؛ به Jira index وصل است.
